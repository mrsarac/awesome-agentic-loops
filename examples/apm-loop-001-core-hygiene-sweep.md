# Receipt Example — APM-LOOP-001 Core Hygiene Sweep

Source: Mustafa Saraç Agentic Project Mesh.

## Goal
Detect drift in source-of-truth docs.

## Proof shape

- Files inspected: README, APM docs, project registry, ledger pointers.
- Finding: contradiction or no-drift statement.
- Action: narrow patch or owner/next-action list.
- Verification: git diff or explicit “no drift found”.

## Why it matters
This loop proves the pattern: a useful loop is not endless autonomy. It is bounded inspection with evidence and a stop condition.
