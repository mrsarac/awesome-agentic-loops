https://github.com/mrsarac/awesome-agentic-loops

2/ The useful question is no longer only:

“What prompt should I type?”

It is:

“What loop should run, what proof should it produce, what state should persist, and when must it stop?”

3/ Every loop in the atlas has a contract:

- trigger
- bounded action
- proof
- memory/state guidance
- stopping condition
- cost guard
- approval gate
- failure modes
- receipt shape

4/ The seed includes 10 proof-grade patterns:

- Core Hygiene Sweep
- Docs/README Milestone Sweep
- Production Error Sweep
- Flaky Test Killer
- PR CI Babysitter
- Stale PR Review Resolver
- Security Headers / OWASP Sweep
- Cost Budget Watch Loop
- Research-to-Public-Artifact Loop
- Agent Mesh Health Loop

5/ The point is boring discipline.

Agents become useful when they are bounded, observable, and accountable.

“Run while you sleep” is not a strategy unless proof, rollback, and cost limits exist.

Motion is not progress; proof is.

If you build with Claude Code, Codex, Cursor, Hermes, OpenCode, or other agent runtimes, this is meant as a practical operating pattern library.

## LinkedIn / blog — short

I published the first seed of **Agentic Loop Atlas** — a proof-oriented registry of reusable AI-agent operating loops.

Most “awesome agent” lists collect tools. This project collects operating patterns: when an agent loop should run, what it is allowed to do, what counts as proof, what memory/state should persist, when it must stop, and which actions need human approval.

The seed includes 10 proof-grade loops for source-of-truth hygiene, production error sweeps, flaky tests, PR CI monitoring, stale review resolution, security headers, cost budget watching, research-to-public-artifact workflows, and agent mesh health checks.

The principle is simple:

> Motion is not progress; proof is.

Repo: https://github.com/mrsarac/awesome-agentic-loops
