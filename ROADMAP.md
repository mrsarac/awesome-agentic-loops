# Roadmap

Agentic Loop Atlas grows by proof, not breadth for its own sake.

## Now

- Keep the first 10 seed loops proof-grade.
- Collect real receipts from Claude Code, Codex, Cursor, Hermes, and OpenCode runs.
- Tighten risk taxonomy and approval gates as failure modes appear.

## Next

- Add platform-specific runbooks for popular agent runtimes.
- Add JSON schema validation in CI.
- Publish a lightweight docs site from `docs/index.html`.
- Add example receipts from real public repositories.

## Later

- Add a small loop search/index tool.
- Track loop maturity: draft → receipt-backed → field-tested.
- Create curated packs: engineering, security, FinOps, research, agent mesh.

## Contribution priorities

1. Receipts for existing loops.
2. Clearer failure modes and approval gates.
3. Minimal, evidence-backed new loops.
4. Platform compatibility notes.
