# Cursor Rule Sketch — AAL-LOOP-009

Use this as a project rule only for repositories where research-to-artifact work is common.

```text
When asked to convert research into a draft, follow AAL-LOOP-009.

Behavior:
- collect a bounded set of sources
- create one artifact, not a broad research dump
- include a source map
- verify claims against sources
- stop before posting, publishing, sending, or deploying
- summarize proof and remaining approval gate

Never publish externally from this rule.
```

Keep this rule project-local. Do not put every atlas loop into global Cursor rules.
