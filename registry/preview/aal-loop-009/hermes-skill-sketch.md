# AAL Research-to-Public-Artifact Skill Sketch

Use when the user wants research converted into a reusable/public-ready artifact.

Source loop card: `AAL-LOOP-009 Research-to-Public-Artifact Loop`

## Workflow

1. Define the artifact target.
2. Collect bounded sources.
3. Build a source map.
4. Draft one artifact.
5. Check claims against evidence.
6. Run risk/approval review.
7. Stop before external publication.
8. Return a receipt.

## Approval gate

Do not post, publish, release, send, deploy, or modify external systems without explicit human approval.

## Receipt

Include:

- sources used
- artifact path or draft text
- claim/evidence summary
- safety/risk notes
- what still needs approval

## Failure modes

- source hoarding instead of artifact creation
- unsupported public claims
- accidental external publication
- no receipt
