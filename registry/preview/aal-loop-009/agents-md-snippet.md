# AGENTS.md Snippet — AAL-LOOP-009

Copy this into a project `AGENTS.md` when you want agents to turn research into public-ready artifacts without posting externally.

```md
## Research-to-Public-Artifact operating loop

When the user asks for research that should become a public artifact, follow `AAL-LOOP-009 Research-to-Public-Artifact Loop`.

Source loop card: `loops/aal-loop-009-research-to-public-artifact-loop.md`

Rules:
- collect bounded sources
- maintain a source map
- separate claims from evidence
- draft one public-ready artifact
- run a safety/risk check
- stop before external publication
- produce a receipt

Approval gate:
- Do not post, publish, release, send, or deploy without explicit human approval.

Receipt must include:
- source URLs
- artifact path
- claim/evidence summary
- risk notes
- next decision needed, if any
```
